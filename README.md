# Manual de consulta de tesis · Educación Primaria

Sitio de consulta por temas: una página por tema, índice enlazado, botones de tema anterior y siguiente, buscador, ruta según la modalidad y calculadoras de validación.

## Publicar en GitHub Pages

1. Crea un repositorio **público** en GitHub (por ejemplo, `manual-tesis`).
2. Sube **todo el contenido de esta carpeta** (incluida la carpeta `img`) con **Add file → Upload files** y confirma con **Commit changes**.
3. Ve a **Settings → Pages**. En **Source** elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`, y pulsa **Save**.
4. En unos minutos el sitio estará en `https://TU-USUARIO.github.io/manual-tesis/`.

## Otras formas de usarlo

- **Netlify:** arrastra esta carpeta a app.netlify.com/drop.
- **Aula virtual o computadora:** abre `index.html` en el navegador. Para que el buscador y la navegación funcionen igual que en la web, conviene servirla desde un sitio web y no como archivo suelto.

## Actualizar

Reemplaza los archivos que cambien y vuelve a confirmar con **Commit changes**. El enlace no cambia.
